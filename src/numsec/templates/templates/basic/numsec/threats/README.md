# Threats

Generated by `numsec analyze`. Each `THREAT-###/threat.md` carries a marker comment
(`<!-- generated by numsec -->`), and a re-run replaces only marked directories.

- `THREAT-###` ids are positional: most severe first, then by rule id.
- Anything without the marker is yours and is never touched by Numsec.
- Findings are leads, not proofs. Confirm each one against `numsec/architecture.md`
  before opening a change.

Typical next step:

```bash
numsec analyze . --ai-format
```

then ask the assistant to turn a threat into `numsec/changes/FIX-THREAT-###/`.
