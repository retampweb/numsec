# Numsec threat workflow

1. Read `NUMSEC.md`, then `numsec/project.md` and `numsec/architecture.md`.
2. Run the analysis:

   ```bash
   numsec analyze . --ai-format
   ```

3. Read every generated `numsec/threats/THREAT-*/threat.md` and summarise the
   findings by severity before touching code.
4. For the threat the user picks, write `numsec/changes/FIX-THREAT-###/proposal.md`
   and `tasks.md`, then wait for review.
5. After the fix lands, re-run `numsec analyze .` to confirm the finding is gone.

Never edit a file that starts with `<!-- generated by numsec`.
